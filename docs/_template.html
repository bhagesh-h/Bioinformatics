Statistics for Bioinformatics

A statistics curriculum for biological data in R and Python, where every claim is demonstrated by a script you can run. Each module simulates data from a known truth, does the wrong thing first, measures how wrong it is, then does it properly and measures that too.

46 modules per language. Every node below exists twice, once as .py and once as .R.
